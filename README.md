## Selected Projects

### UrduEval — Urdu & Roman Urdu LLM Evaluation Framework
https://github.com/mustafaabadshah/Urdu-Eval
- Provider-agnostic evaluation harness with benchmark adapters, normalization profiles, diagnostic reports, and reproducible runs; published on PyPI.
- Implements ExactMatch, accuracy, F1, BLEU, chrF++, ROUGE-L, LLM-as-a-judge, bootstrap/Wilson confidence intervals, and SHA-256 dataset auditing.

### RAG-Eval — Framework-Agnostic RAG Evaluator
https://github.com/mustafaabadshah/rag-eval
- Lightweight Python CLI/library to score retrieval precision@k and answer faithfulness without requiring a specific RAG framework or API key.
- JSONL evaluation, optional LLM-as-a-judge support, FastAPI examples, and adapters for LangChain and Haystack; published as rag-eval-py.

### Meta-Graph Codebase Navigator
- Code-intelligence platform parsing Python source with AST analysis and creating a source-code knowledge graph for multi-hop architectural questions.
- Integrated Neo4j, NetworkX, LangGraph retrieval/reasoning, FastAPI, and a React/TypeScript graph explorer.

### Self-Healing Code Repair Pipeline
- Multi-agent workflow where a Coder proposes repairs and a Critic validates them against target and regression tests in a sandboxed workspace.
- Implements conditional retry, rollback, bounded attempts, and human escalation; includes FastAPI, React/Vite, Docker/local sandbox support, and tracing.

### Industrial Fabric Classification System
- Co-developed with U.S. denim mills, reporting 99.96% joint accuracy across manufacturing classes and structural configurations.
