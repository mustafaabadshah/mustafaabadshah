- HTML report generation and metrics visualization

**Use Cases:**

- Continuous evaluation pipelines for production LLMs

**Tech Stack:** Python, CLI tooling, Ollama, OpenAI, Anthropic, Hugging Face, SQLite, Statistical Analysis

### 💎 [rag-eval: RAG Quality & Faithfulness Evaluation Toolkit](https://github.com/mustafaabadshah/rag-eval)

**Keywords:** RAG evaluation, retrieval quality, answer faithfulness, LLM assessment, semantic search evaluation, RAG pipeline testing

A **framework-agnostic evaluation toolkit** for assessing RAG (Retrieval-Augmented Generation) systems. Measure retrieval quality and answer faithfulness without vendor lock-in.

**Features:**
- **Retrieval Evaluation** — Precision@k, Recall, MRR (Mean Reciprocal Rank)
- **Faithfulness Scoring** — Claim extraction, context alignment, semantic overlap analysis
- **Multiple Interfaces** — Python API, Command-Line Interface (CLI), FastAPI microservice
- **Format Support** — JSONL input/output, structured predictions, batch processing
- **Framework Integration** — Native adapters for Haystack and LangChain pipelines
- **LLM-as-Judge** — Optional semantic analysis using LLMs for deeper evaluation
- **Offline & Online** — Works with local models (Ollama) or cloud providers

**Use Cases:**
- Evaluate RAG pipeline quality before production deployment
- A/B test retrieval strategies
- Monitor answer quality in production RAG systems
- Benchmark different embedding models and retrievers
- Integration with CI/CD pipelines for continuous evaluation

**Tech Stack:** Python, FastAPI, Pydantic, CLI, Haystack, LangChain, LLM Integrations
