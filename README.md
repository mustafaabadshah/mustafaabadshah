## Featured projects

### [Urdu-Eval](https://github.com/mustafaabadshah/Urdu-Eval)
An open evaluation harness for **Urdu and Roman Urdu AI**. It brings together benchmark execution, model-provider integrations, linguistic normalization, metrics, diagnostics, confidence intervals, caching, and reproducible reports.

- Supports local and hosted providers such as Ollama, OpenAI, Anthropic, and Hugging Face
- Includes Urdu QA, reasoning, translation, summarization, Roman Urdu, UrduMMLU, and UrBLiMP workflows
- Provides dataset validation, benchmark verification, run manifests, HTML reports, and leaderboard-oriented comparisons

**Stack:** Python, CLI tooling, Ollama, OpenAI, Anthropic, Hugging Face, SQLite

### [rag-eval](https://github.com/mustafaabadshah/rag-eval)
A framework-agnostic toolkit for evaluating **retrieval quality and answer faithfulness** in RAG systems without forcing a particular orchestration framework or requiring API keys.

- Measures retrieval with Precision@k
- Scores answer faithfulness using claim/context overlap
- Provides Python APIs, a CLI, JSONL input, a FastAPI microservice, and adapters for Haystack and LangChain
- Includes optional LLM-as-a-judge support for cases requiring deeper semantic analysis

**Stack:** Python, FastAPI, Pydantic, CLI tooling, Haystack adapters, LangChain adapters

### [Chest CT Classification MLOps](https://github.com/mustafaabadshah/Chest-CT-Scan-Classification-MLOps)
An end-to-end deep-learning and MLOps project for chest CT disease classification. The project demonstrates how to organize a model through ingestion, preparation, training, evaluation, serving, and deployment.

- Uses transfer learning with a VGG16-based architecture
- Tracks experiments and evaluation results with MLflow/DagsHub
- Uses DVC to define and reproduce pipeline stages
- Serves predictions through a Flask web application and API
- Includes Docker-based execution and cloud-oriented CI/CD workflows

**Stack:** Python, TensorFlow, Keras, VGG16, DVC, MLflow, Flask, Docker, AWS

### [NewsNinja](https://github.com/mustafaabadshah/AI-powered-news-and-Reddit-audio-summarizer)
An AI-powered news and Reddit audio briefing application that collects current information, summarizes it, and turns it into listenable updates.

- Retrieves news and Reddit content through scraping workflows
- Uses LLM-based summarization for concise briefings
- Generates speech with ElevenLabs or gTTS
- Combines a FastAPI backend with a Streamlit interface

**Stack:** Python, FastAPI, Streamlit, Bright Data, Anthropic, ElevenLabs, gTTS

### [Chat with PDF using RAG](https://github.com/mustafaabadshah/chat-with-pdf-using-RAG-DeepSeek)
A local document question-answering application for uploading PDFs, extracting their content, creating embeddings, and answering questions with retrieval-augmented generation.

**Stack:** Python, LangChain, Streamlit, Ollama, DeepSeek
